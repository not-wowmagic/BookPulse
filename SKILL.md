# BookPulse Cinematic Engine

## Expertise

- **GSAP 3**: ScrollTrigger pin/scrub animations, SplitText character-level reveals, stagger sequences with custom easing, timeline orchestration, morphSVG for data visualizations.
- **React 19**: Concurrent rendering patterns, useEffect-driven data polling, component composition for cinematic UI, ref-based GSAP integration with useGSAP cleanup.
- **Cinematic UI Patterns**: Full-bleed hero sections with gradient overlays, floating navbar islands, scroll-triggered stacking cards, monospace telemetry feeds, noise texture overlays, weighted scroll physics.

## Design System — Brutalist Signal (Preset C)

### Palette
| Token         | Hex       | Usage                          |
|---------------|-----------|--------------------------------|
| Paper         | `#E8E4DD` | Primary background             |
| Signal Red    | `#E63B2E` | Accents, CTAs, active states   |
| Off-white     | `#F5F3EE` | Card backgrounds, surfaces     |
| Black         | `#111111` | Primary text, overlays         |
| Mid-gray      | `#6B6B6B` | Secondary text, borders        |

### Typography
| Role      | Font Family             | Weight | Usage                    |
|-----------|-------------------------|--------|--------------------------|
| Heading   | Space Grotesk           | 700    | All headings, nav        |
| Drama     | DM Serif Display Italic | 400i   | Hero statements, quotes  |
| Data      | Space Mono              | 400    | Telemetry, stats, code   |

### Spacing & Radii
- Container radius: `2rem` (32px)
- Card padding: `2rem`
- Section vertical spacing: `8rem`
- Noise overlay: `0.05` opacity, fixed position, pointer-events none

### Animation Rules
- Default ease: `power3.out`
- Scroll-triggered reveals: `power2.inOut`
- Stagger delay: `0.08s` per element
- Duration range: `0.6s` (micro) to `1.4s` (hero)
- No bounce easing. No elastic. Every motion must feel weighted and intentional.
